# kitsu-native

JSON:API 1.1 client using native fetch. Requires Node 22, 24, or 26+, Bun or a modern browser.

```js
import KitsuNative from 'kitsu-native'
const api = new KitsuNative({ baseURL: 'https://kitsu.app/api/edge' })
const { data } = await api.get('anime')
```

Resource methods match kitsu. Inject transport with `fetch`; pass native options through `fetchOptions`.
`fetchOptions` cannot override generated method, headers, or body. Request options override constructor defaults.
`.fetch` remains alias for `.get`. Axios instance, Axios options, and interceptors belong to kitsu only.
Change client headers with `api.headers.set(name, value)`. Per-request headers override defaults without changing client headers.
HTTP and parsing failures throw `KitsuNativeError` with `response`, `status`, `headers`, `document`, `errors`, and parsing `cause`.
Network and cancellation errors propagate from fetch. Timeout defaults to 30,000 ms; set `timeout: 0` to disable it.

Set `attributeCase: 'kebab'` or `'snake'` to read camelCase attributes and write the
selected wire case. Default `'none'` preserves names. Nested JSON keys,
relationships, and query names stay unchanged. See [migration guidance](MIGRATING.md).

Document metadata stays beside `data`; resource metadata lives under `$`.
`hoistData` unwraps only documents containing solely `data`. Relationships always flatten.

### KitsuNative

JSON:API client using native fetch, with kitsu resource methods and aliases.

#### Parameters

*   `options` **[Object](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Object)?** Client options; fetch defaults to globalThis.fetch (optional, default `{}`)

    *   `options.attributeCase` **(`"none"` | `"kebab"` | `"snake"`)** Convert resource attribute names to camelCase on reads and selected wire case on writes. Nested JSON, relationships, and queries stay unchanged. (optional, default `none`)

#### Examples

```javascript
const api = new KitsuNative({ baseURL: 'https://kitsu.app/api/edge' })
const response = await api.get('anime')
```
